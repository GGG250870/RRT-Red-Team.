# Evidence Index

Ogni Evidence Pack deve conservare:
- source_id
- evidence_id
- URL
- observed_at
- channel
- entity_scope
- confidence
- claim
- data_state
- audit_ref

Nessun finding può esistere senza evidence_id valido.
